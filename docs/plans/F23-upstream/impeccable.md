## Local 3.9.1 vs latest 4.3.1 (diff -rq, verified)

- **Removed:** `brand.md`, `product.md`, `interaction-design.md`, `codex.md`. The Node scripts are gone too (`context.mjs`, `detect.mjs`, `palette.mjs`, `live-*.mjs`, `detector/`).
- **Added:** `craft-floor.md` (the new quality floor and ban list), `new-work.md` (the build flow), `operate.md` (what `product.md` became), `generate.md`, `visualize.md`, `doctor.md`, `live-setup.md`, `routing.md`, and `degraded/` (fallbacks for hosts with no subagents). - **Every other reference differs.** `craft.md` is now a 5-line deprecated alias. SKILL.md went from 169 to 86 lines: its "General rules" and "Absolute bans" moved into `craft-floor.md`.
- **Two registers became four modes.** Brand/Product is now **Persuade / Operate / Read / Experience** (SKILL.md:33-40). Most bans are now "the category's defaults, not bans" that a brief can earn back (craft-floor.md:21).
- **Scripts became a binary.** `scripts/impeccable` is a sh/cmd launcher for a self-contained Rust binary: `context`, `detect`, `concept-seed`, `comp-diff`, `critique-storage`, `surface-brief` and more. No Node is needed.
- **Arwen tracks 3.9.1 closely.** Many arwen lines are near-verbatim 3.9.1 text: contrast, the 6rem clamp, -0.04em, the z-index scale, reveal gating, and the cream-band OKLCH numbers. That includes one factual error, which is row 1 below (inferred from text match).

## Arwen rules the upstream contradicts

1. **Large-text threshold** (row 1). Arwen `craft.md:11` "≥18px / bold ≥14px" against upstream's detector 24px / 18.67px. **Upstream is right.** WCAG 2.x defines large text as 18pt or 14pt bold, and CSS px = pt × 4/3. Arwen copied the 3.9.1 prose, which had the same unit slip. Upstream's prose dropped the px figure (craft-floor.md:9), and its code has the correct numbers.
2. **Tinted neutrals are required in arwen and optional upstream.** Arwen SKILL.md:167: "Tint neutrals 0.005–0.015 toward the brand hue". Upstream colorize.md:44: "Tint neutrals only when the brand hue genuinely creates cohesion. Neutral gray is valid when it serves the world." **Upstream is right.** A mandatory tint is itself a cross-project monoculture move, which is the same argument 3.9.1 made against default-warm tints. Keep the range as the default and drop the "never untinted" reading.
3. **Accent ≤10% (Restrained).** Arwen SKILL.md:165 against upstream colorize.md:27: "it must follow the brief and selected world rather than a fixed percentage rule". **Mostly upstream.** Nobody measures coverage, so ≤10% is a heuristic, not a check. Keep the number as a guide and keep it out of the gate.
4. **Eyebrow/kicker.** Upstream craft-floor.md:27 says "This one is a ban, not a default: no brief earns it back." Arwen treats it as contested (anti-slop §2 †) and lets the brief win (SKILL.md:218). **Arwen is right.** Upstream contradicts its own SKILL.md:27, "The brief wins. Honor pinned aesthetics…". An absolute ban that overrides the user is the load-order-style conflict arwen's floor exists to prevent.
5. **Reduced motion "instant"** (row 6). Arwen `craft.md:69` "crossfade or instant" against upstream's "not disabling all motion". **Upstream is right.** State-confirming feedback (a checkmark, a colour change) is information, and removing it trades a vestibular fix for a comprehension bug.
6. **Upstream's own internal conflicts that arwen already resolves.** harden.md:80 says "Use `clamp()` for fluid typography", against operate.md:14's "Fixed rem scale, not fluid". craft-floor.md:15 says "theme custom scrollbars", against operate.md:50's "Reinventing… custom scrollbars". Arwen's register split (SKILL.md:105-107) is the right resolution. Do not import either line without a register.
