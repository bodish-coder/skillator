Ops pane layouts for F111

Four ways for the ops-board pane to fit any width. Every frame below came from one script that fails if a line runs past its column count or a frame passes 14 rows, and that checks each of the eight actions is on screen or one named key away. Same board data in every frame.

  • no line > cols
  • 14 rows max
  • regions own their rows
  • the list yields rows first
  • no action unreachable

How to choose

Reply with a letter, or a mix such as "D, with A's rail below 60". The pick becomes F111's design, and the build adds the same width check to the pane's plugin tests at 40, 60, 80 and 120 columns.

These are mocks built from the layout rules, not frames captured from the pane. Glyphs are the UTF-8 set; the ASCII fallback is not shown.
