Ops pane styles for layout B

Layout B is picked: tabs, keys and the count line wrap whole words and are never shortened, and the list gives up rows first. These are four visual treatments of that same layout, built by the same checks: no line past its width, 14 rows, all eight actions on screen at every width. Style 4 is also checked to contain no character above ASCII 127.

  • layout B
  • no line > cols
  • 14 rows max
  • all 8 actions on screen
  • style 4: ASCII only

How to choose

Reply with a number, or a mix such as "2, with 3's keycaps". Whatever you pick, style 4 ships as the ASCII fallback the pane switches to when the console cannot draw Unicode.

These are mocks built from the layout rules, not frames captured from the pane.
