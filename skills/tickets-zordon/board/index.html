Where this board comes from

Dropping a file anywhere on this page does the same thing. Nothing is uploaded and nothing is stored: the file is read in the browser and the page forgets it on reload.

Re-baking the built-in snapshot

A page opened from file:// is not allowed to read a sibling file, so the board ships with a snapshot of TICKETS.md baked in. One command refreshes it, from the repo root: 

node board/refresh.mjs

Use the file picker above for a quick look at an edited board. Use the command when the snapshot in this file should be current for everyone.
